# Raihanul Islam - Portfolio

Personal portfolio built with Next.js (App Router) and vanilla CSS.

## Getting Started

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Optional environment variables

| Variable | Purpose |
| --- | --- |
| `NEXT_PUBLIC_SITE_URL` | Deployed site URL, used for Open Graph / social preview links |
| `NEXT_PUBLIC_FORM_ENDPOINT` | Form service URL (e.g. a Formspree endpoint). Without it, the contact form opens the visitor's email app instead |

## Resume

The Download Resume button serves `public/resume.pdf`. Replace that file to update it.
